Welcome to the **PETRONAS CTF 2026 Preliminary Round** repository!

## Writeup Format

Each challenge directory contains its own `README.md` documenting the challenge and its solution.

Every writeup follows a simple structure:

1. **Challenge** — The original challenge description and any relevant context.
2. **Solution** — The approach, analysis, techniques, commands, and scripts used to solve the challenge.
3. **Flag** — The recovered flag.

Supporting materials such as screenshots, source code, scripts, and extracted files will be stored alongside their respective writeups.
